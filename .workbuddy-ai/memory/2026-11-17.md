## Pravi vzrok 500-ih na DB poteh — REŠENO v kodi (2026-11-17, del 2)

- **Prejšnja diagnoza "10ms CPU" je bila napačna za zadnje napake.** Svež `wrangler tail` je pokazal `cpuTime: 24–339 ms` z `outcome: ok`. Pravi vzrok:
  ```
  Cannot perform I/O on behalf of a different request.
  Connection terminated
  Worker ... canceled this request because it detected that your code had hung
  ```
- **Root cause:** modulski singleton `PrismaClient` z WebSocket `PrismaNeon` poolom. Pool se ustvari v kontekstu prve zahteve; naslednje zahteve ga ponovno uporabijo — Workers prepove dostop do I/O objekta iz druge zahteve.
- **Popravek v `src/lib/prisma.ts`:** request-scoped client prek `AsyncLocalStorage` + Proxy. Vsaka zahteva dobi svoj client/pool. Proxy posreduje vse klice (vključno ~80 `$transaction()`) brez sprememb klicnih točk.
  - **Turbopack past (pomembno):** statičen `import { AsyncLocalStorage } from "node:async_hooks"` je padel v buildu: `chunking context does not support external modules (request: node:async_hooks)` — uvoz se je prek "use server" action-ov potegnil v client chunk. Rešitev: uporabi `globalThis.AsyncLocalStorage` (Next.js `node-environment-baseline.js` in OpenNext banner ga že nastavita), s fallbackom na en client v čistem Node/test okolju. **Ne dodajati statičnega node:async_hooks uvoza nazaj.**
  - Verificirano: `next build` = EXIT 0, "Compiled successfully in 81s", 0 async_hooks napak.
- **Prisma verzijski skew:** `@prisma/client 6.19.0` + `@prisma/adapter-neon 7.10.1` (ta je potegnil `@prisma/driver-adapter-utils 7.10.1`). Popravljeno: adapter piniran na `6.19.3` (isti `driver-adapter-utils 6.19.3`). Opomba: pin se je med delom dvakrat povrnil na `^7.10.1` zaradi sočasnih externih commitov — vedno preveriti pred commitom.
- Odstranjena mrtva datoteka `src/lib/public-home-consolidated.ts` (ni bila nikamor uvožena, 13 TS napak, napačni uvozi iz `@/lib/site-content` namesto `@/lib/verticals`, neobstoječ `faq` v `_count`). Nobena funkcija izgubljena.
- **Sočasna aktivnost:** med delom so prispeli 3 externi commiti (241efb3 cron→Vercel, ed498de diag workflow, 8c17cbc nav/footer) in tekel CI run brez mojih popravkov. Pred vsakim commitom preveriti `git status` in `git log`.
- **Stanje:** popravek je committan in potisnjen v CI; čaka se na deploy + `wrangler tail` verifikacijo, da cross-request I/O napak ni več.
